# Cloud Provider Comparison

## Service Comparison Table
| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|---|---|---|---|
| *Compute* | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| *Storage* | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| *Networking* | Amazon VPC | Azure Virtual Network | Google VPC |
| *Identity & Access Management (IAM)* | AWS IAM | Azure RBAC / Azure AD | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
AWS offers the widest range of services. As the oldest major cloud provider, it provides over 200 fully-featured services covering compute, storage, databases, AI, analytics, and enterprise tools. Its extensive ecosystem supports nearly every use case, giving it deeper coverage and more mature service offerings than competitors.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is the best choice. It integrates seamlessly with Microsoft technologies like Windows Server, Active Directory, SQL Server, and Office 365. Since they share the same ecosystem, migration is easier, compatibility is better, and management is unified — reducing complexity and cost for Microsoft-based environments.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform is widely recognized in these areas. Google created Kubernetes and continues to lead its development, making GCP the best platform for container orchestration. It also offers advanced AI and ML tools built on the same technology Google uses internally, giving it a strong advantage in intelligent cloud services.

### 4. What similarities did you observe among the three cloud providers?
All three follow the same core infrastructure model — they all provide compute, storage, networking, and identity management as fundamental services. They use pay-as-you-go pricing, operate global data centers, ensure high availability, and follow the same IaaS principles — just under different product names.
