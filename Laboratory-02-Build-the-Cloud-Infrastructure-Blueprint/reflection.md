# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?
I believe Compute is the most important component. While storage and networking are essential, compute is what actually makes things happen — without processing power, you cannot run applications, process data, or perform any work. Storage just holds data and networking just connects them, but compute is the engine that powers everything in the cloud. If you have enough compute, you can scale and support other resources; without it, nothing functions.

## 2. How does Linux support cloud computing?
Linux is the foundation of most cloud environments because it is open-source, lightweight, stable, and very secure. Almost all cloud servers run on Linux because it is highly customizable and uses fewer system resources. It provides the operating system that runs containers, virtual machines, and cloud tools. Linux also has powerful command-line tools that make it easy to automate, manage, and deploy cloud infrastructure remotely.

## 3. Why is technical documentation important before deploying infrastructure?
Documentation acts as a blueprint and guide — it ensures everyone understands the design, components, and setup before anything is built. It prevents mistakes, makes troubleshooting easier, and allows others to maintain or update the system later. Without documentation, you might forget how things were set up, leading to errors, downtime, and confusion especially when working in teams or scaling up infrastructure.
