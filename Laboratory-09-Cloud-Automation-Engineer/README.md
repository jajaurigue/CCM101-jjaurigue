# Laboratory 09 - Cloud Automation Engineer

## Mission Overview

This mission focuses on automating server administration tasks using Bash scripting and Linux Cron. I will create a backup script that compresses application data into a timestamped archive and configure a scheduled task to run it automatically.

## Objectives

- Understand Bash scripts, variables, and shebang syntax.
- Create a script that backs up application data.
- Set executable permissions using chmod.
- Schedule an automated task using crontab.
- Document the backup script and Cron configuration.
- Complete the Cloud Computing GitHub portfolio.
