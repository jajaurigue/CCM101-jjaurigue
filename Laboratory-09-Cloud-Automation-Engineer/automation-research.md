# Automation Research

## 1. Bash Script

A Bash script is a text file containing commands that the Linux Bash shell can execute in sequence to automate tasks. The `#!/bin/bash` line, called the shebang, tells the system which interpreter should execute the script.

## 2. Variables

Variables store values, such as folder paths, that a script can reuse whenever needed. For example, using `$BACKUP_DIR` makes it easier to change the backup location in one place instead of editing several commands.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at specified times. It is important in cloud operations because it helps automate recurring tasks, such as backups, and reduces the need for manual execution.
