# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that provides cloud services for businesses and organizations.

## Global Infrastructure

GCP provides a global cloud infrastructure designed to deliver reliable, scalable, and high-performance cloud services.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services.

## Four Core Services

1. Compute Engine – Compute service for running virtual machines.
2. Cloud Storage – Object storage service for storing data.
3. Virtual Private Cloud (VPC) – Networking service for connecting cloud resources.
4. Cloud Identity – Identity and access management service.

## Three Advantages

1. Strong capabilities for Artificial Intelligence and Machine Learning.
2. Strong support for Kubernetes and containerized applications.
3. Scalable and global cloud infrastructure.

## Typical Enterprise Use Cases

GCP can be used for data analytics, Artificial Intelligence and Machine Learning, web applications, containerized applications, and large-scale business systems.
