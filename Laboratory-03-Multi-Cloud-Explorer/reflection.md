# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is Google Cloud Platform (GCP). I like how it supports Artificial Intelligence, Machine Learning, and Kubernetes. I also learned that it can be useful for modern applications and large projects.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP have many similarities because they all provide important cloud services such as computing, storage, networking, databases, and identity management. They also allow businesses to use scalable and flexible cloud resources without depending only on physical servers.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when choosing a cloud provider because every organization has different needs. Budget, existing technology, security, scalability, and the type of application can affect the decision. The best cloud platform is the one that matches the needs of the business.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider is not simply about choosing the most popular one. A Cloud Solutions Consultant should first understand the client's needs and then recommend the services that can solve their problems. This activity helped me think more carefully about technical decisions.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub Cloud Computing Portfolio became more organized and meaningful after completing this mission. I added research about AWS, Azure, and GCP, compared their services, and created recommendations for different clients. This activity also helped me improve my Markdown and documentation skills.
