# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides cloud services for businesses and organizations.

## Global Infrastructure

Azure provides a global cloud infrastructure designed to deliver reliable and scalable services.

## Cloud Management Console

The Azure Portal is a web-based interface used to manage Azure resources and cloud services.

## Four Core Services

1. Azure Virtual Machines – Compute service for running virtual machines.
2. Azure Blob Storage – Object storage service for storing data.
3. Azure Virtual Network – Networking service for connecting Azure resources.
4. Microsoft Entra ID – Identity and access management service.

## Three Advantages

1. Strong integration with Microsoft technologies.
2. Scalable and flexible cloud services.
3. Supports enterprise organizations and applications.

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, virtual machines, data storage, business systems, and Microsoft-based workloads.
