# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of cloud services for businesses and organizations.

## Global Infrastructure

AWS operates a global cloud infrastructure designed to provide reliable and scalable cloud services.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

## Four Core Services

1. Amazon EC2 – Compute service for running virtual servers.
2. Amazon S3 – Object storage service for storing data.
3. Amazon VPC – Networking service for creating isolated virtual networks.
4. AWS IAM – Identity and access management service.

## Three Advantages

1. Wide range of cloud services.
2. Scalable and flexible infrastructure.
3. Supports organizations of different sizes.

## Typical Enterprise Use Cases

AWS can be used for web applications, data storage, enterprise applications, backup and recovery, and scalable business systems.
