# Laboratory 10 – Enterprise Cloud Architect

## Overview
This laboratory activity focuses on designing, deploying, securing, and automating an enterprise cloud infrastructure.

## Objectives
- Design an enterprise cloud architecture.
- Deploy a multi-container application using Docker Compose.
- Configure firewall security using UFW.
- Create a Bash automation script.
- Schedule automated tasks using Cron.
- Document the infrastructure and operational procedures.

## Project Components
1. Architecture Diagram
2. Docker Compose Configuration
3. Firewall Configuration
4. Automation Script
5. Operational Manual
6. Final Reflection
