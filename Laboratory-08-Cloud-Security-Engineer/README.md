# Laboratory 08 - Cloud Security Engineer

## Mission Overview

This mission focuses on securing a Linux web server using the Uncomplicated Firewall (UFW). It demonstrates how to reduce the attack surface and allow only the network traffic required by the application.

## Objectives

- Understand the Principle of Least Privilege.
- Identify the attack surface of a server.
- Configure a Default Deny firewall policy.
- Allow SSH and application traffic on port 8080.
- Document security practices and provide screenshots as evidence.
