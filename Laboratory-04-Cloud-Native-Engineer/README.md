# Laboratory 04 - Cloud-Native Engineer

## Mission Overview

This laboratory activity introduces cloud-native engineering through containerization. The activity compares virtual machines and containers and demonstrates how Docker can be used to deploy and manage an Nginx web server quickly.

## Objectives

- Differentiate virtual machines and containers.
- Verify Docker in a Linux environment.
- Pull and run an Nginx container.
- Map host port 8080 to container port 80.
- Test the web server using curl.
- Manage the Docker container lifecycle.
- Document Docker operations using Markdown.
