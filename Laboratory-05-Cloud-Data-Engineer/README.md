# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud storage and object storage. The mission involves deploying an S3-compatible MinIO storage server using Docker, accessing its web console, creating a storage bucket, and uploading a test object.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using Docker.
- Access a cloud service through port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Understanding different types of cloud storage
- Deploying services using Docker
- Working with environment variables
- Using port forwarding
- Creating and managing object storage buckets
- Uploading objects to cloud storage
- Documenting technical procedures using Markdown
