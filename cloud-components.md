# Cloud Infrastructure Components
 ## 1. Compute Resources
 - *Purpose:* Handles all processing, calculations, and execution of applications and tasks. It is the "brain" that runs the workloads.
 - *Why Important in Cloud Computing:* Compute is the core engine — without processing power, nothing can run. Cloud allows you to scale compute up/down instantly based on demand.
 - *Linux Environment Example:* The Intel Xeon CPU (1 core) processes all commands, runs system services, and executes programs in the KillerCoda Ubuntu environment.
 ## 2. Storage Resources
 - *Purpose:* Stores, retains, and manages data, files, applications, and system information permanently or temporarily.
 - *Why Important in Cloud Computing:* Cloud needs reliable, scalable storage to save data that can be accessed from anywhere at any time. Storage can grow independently as needed.
 - *Linux Environment Example:* The 19GB disk (/dev/vda1) holds the OS, files, and user data; /boot stores kernel files and /boot/efi holds boot configuration.
 ## 3. Networking Resources
 - *Purpose:* Enables communication between servers, users, and other services; connects everything together and provides internet access.
 - *Why Important in Cloud Computing:* You cannot access or use cloud resources without networking. It allows remote management, data transfer, and connection across global regions.
 - *Linux Environment Example:* IP addresses 172.30.1.2 and 172.17.0.1 let us connect and interact with the Linux server remotely.
 ## 4. Operating System
 - *Purpose:* Manages hardware resources, runs applications, and acts as the interface between the user and the infrastructure.
 - *Why Important in Cloud Computing:* Almost all cloud servers run on Linux — it is open-source, lightweight, stable, secure, and highly customizable. It is the foundation of every cloud instance.
 - *Linux Environment Example:* Ubuntu 24.04.4 LTS manages the CPU, memory, disk, and network — making all other components work together.
